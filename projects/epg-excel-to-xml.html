EPG Excel-to-XML Automation

An automation workflow that transforms broadcaster programme schedules (EPG data) from Excel spreadsheets into structured XML, with validation built in, and prepares the result for FTP ingestion.

The challenge

Programme schedules are often maintained in spreadsheets, but the systems that ingest them expect structured XML. Converting by hand is slow and repetitive, and small mistakes, such as a wrong channel or programme ID, an incorrect date or time, or a broken thumbnail link, can flow straight through to the programme guide.

What I built

A Python workflow reads the programme schedule from Excel and generates structured XML from it. Alongside the conversion, it validates channel IDs and programme IDs, verifies dates and times, and checks thumbnail URLs. The finished output is then prepared for FTP ingestion.

Key features

  • Excel spreadsheet processing
  • XML generation
  • Channel ID and programme ID validation
  • Date and time verification
  • Thumbnail URL checks
  • Preparation for FTP ingestion

How it fits together

What this demonstrates

Structured-data transformation with validation built in: taking human-maintained spreadsheets and producing machine-ready output. It is a clear example of automating repetitive work that is easy to get wrong by hand.
