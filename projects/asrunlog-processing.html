AsRunLog Processing

Processing of broadcast transmission logs, the as-run logs that record what actually went to air, and preparation of that data for downstream systems, including workflow support for ingestion into HDFS.

The challenge

As-run logs record what was actually transmitted, which makes them useful well beyond the control room. But downstream data systems can only use them once they are in a consistent, structured form that fits an ingestion pipeline.

What I built

Transmission logs are processed with Python and turned into structured data that is prepared for downstream systems, with supporting workflow for ingestion into HDFS.

Key features

  • Transmission-log processing
  • Structured data preparation
  • Workflow support for HDFS ingestion

How it fits together

  1. 1Collect transmission (as-run) logs
  2. 2Process and structure the log data
  3. 3Prepare the data for downstream systems
  4. 4Support ingestion into HDFS

What this demonstrates

Data-engineering fundamentals: turning operational logs into structured data and fitting it into a larger data pipeline.
