Blackmagic Videohub Controller

A Python desktop application for controlling Blackmagic Videohub video routers. It communicates with the router over the network and gives operators a desktop interface for routing control workflows.

The challenge

A video router decides which source feeds which destination: cameras, recorders, monitors and more. Routing changes need to be quick and dependable. This tool puts routing control into a focused desktop interface that talks to the router directly over the network.

What I built

The desktop interface is built in Python with Tkinter / CustomTkinter. It communicates with the Videohub over the network using Python sockets and the router’s text-based control protocol (the same protocol that can be explored over Telnet), so routing actions taken in the interface are sent straight to the equipment.

Key features

  • Desktop GUI built with Tkinter / CustomTkinter
  • Network-based communication with the router
  • Routing control workflows
  • Integration with broadcast equipment

How it fits together

  1. 1Connect to the Videohub over the network
  2. 2Choose a source and a destination in the desktop interface
  3. 3Send the routing change to the router

What this demonstrates

Building practical desktop software that controls real hardware: network programming with sockets, working against a device’s control protocol, and wrapping it in an interface that is straightforward for operators.
