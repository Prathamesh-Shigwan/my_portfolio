About

A hands-on developer who understands both software and the real-world systems it has to work with.

I’m Prathamesh Shigwan, a software developer based in Mumbai, India. I build web applications, desktop tools and automation that make complex workflows simpler.

Much of my work sits where software meets real-world operations: spreadsheets that need to become structured data, media files that must be checked before they are used, and equipment that has to be controlled over a network.

I hold a Bachelor of Science in Computer Science from the University of Mumbai, completed in May 2023. My hands-on experience covers Python development, Django web applications, desktop applications, API and network integrations, and broadcast engineering, including workflow automation, data processing and technical R&D.

Working alongside live broadcast operations taught me to value reliability: automation should check its inputs and fit the way people actually work. I bring the same approach to software for businesses.

How I approach work

Start from the real workflow

Time spent in broadcast operations taught me to understand how work actually happens (schedules, files, equipment, people) before writing code.

Build the checks in

Validating IDs and timings, flagging missing files, confirming media is ready: good automation catches problems before they reach anyone else.

Connect what already exists

Routers, recorders, spreadsheets, FTP servers, payment and shipping services: most useful software works with the tools a team already relies on.
